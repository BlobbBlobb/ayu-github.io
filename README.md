# Personal Research Portfolio (GitHub Pages starter)

A self-contained, mobile-friendly academic and technical portfolio. The design is original and takes general inspiration from clean, minimal research websites.

## 1. Personalize

Open `index.html` in an editor (VS Code is easy):

- Replace every **Your Name** and the brand initials **YN**.
- Replace `your.email@example.com` and the GitHub and LinkedIn URLs (`https://github.com/` and `https://www.linkedin.com/`).
- Revise the About, Research, Projects, Experience and Education text to be accurate and appropriate for public release.
- To add your own photo, edit the `.hero-visual` element in `index.html` and add the photo to the `assets/` folder; alternatively, keep the decorative illustration.
- Change colors, fonts, layout or spacing in `styles.css`.
- Only add an actual resume or paper link once that file or published URL exists.
- Never include private client/research data or access credentials.

## 2. Test locally

Double-click `index.html` to view it in your browser. Optionally run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## 3. Publish on GitHub Pages

1. Create a **public** repository named **YOUR-GITHUB-USERNAME.github.io** (using your exact GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, and `assets/` to the repository root. Commit the changes to the `main` branch.
3. Navigate to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then choose **main** and **/(root)**. Save.
5. Your website should become available at `https://YOUR-GITHUB-USERNAME.github.io/` after the deployment completes (publication can take several minutes).

For authoritative instructions: https://docs.github.com/en/pages/quickstart

## 4. Ongoing edits

Any new commit to the publishing branch will republish the site. No hosting subscriptions, package manager, or build step required.

## Content note

The sample project descriptions are illustrative and must be reviewed before public publication. Replace private or preliminary details with versions you are comfortable sharing publicly.
